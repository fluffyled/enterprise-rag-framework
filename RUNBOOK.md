# Локальный запуск Enterprise RAG

1. Активируйте окружение Python 3.13 и установите `python -m pip install -r requirements-cuda.txt`. Этот список фиксирует основные версии проверенного CUDA-окружения.
2. Выполните `python scripts/download_models.py --bge` и `python scripts/download_answer_model.py`. Разместите совместимую CUDA-сборку [llama.cpp b12284](https://github.com/ggml-org/llama.cpp/releases/tag/b12284) в `tools/llama-cuda`.
3. Выполните `./start.ps1`. При необходимости передайте `-Python <путь>` и `-Server <путь>`. Launcher ждёт успешной пробной генерации модели и запуска Streamlit на localhost.
4. Откройте [Навигатор](http://127.0.0.1:8501). В разделе «Документы» загрузите PDF, DOCX или XLSX и нажмите «Построить или обновить базу». Эта операция также включает все документы из `data/raw`. Для OCR требуется Tesseract с русским и английским языками.
5. В разделе «Ассистент» задайте вопрос. Для переключения Fast/Quality и Legacy/G2 включите расширенные метаданные в настройках. Fast и Legacy используются по умолчанию.
6. Для удаления загруженного документа используйте раздел «Документы», затем перестройте базу. Запросы блокируются между изменением списка и успешной перестройкой.
7. Выполните `./stop.ps1` для остановки запущенных процессов. Логи находятся в `reports`, диагностические трассы G2 в `data/traces`.

Готовый совместимый индекс можно указать через `NAVIGATOR_INDEX`. Для Quality приложение ожидает совместимые `data/clauses/clauses.json` и `data/source_documents.json`. Профили приложения определены в `configs/application.yaml`. Экспериментальные YAML используются через исследовательские команды.

Для демонстрации оболочки без моделей и документов выполните `python -m streamlit run app.py` и выберите демонстрационный режим. Для реальной демонстрации возьмите один DOCX с пунктом «1. Сотрудник направляет заявку на пропуск в отдел кадров за три рабочих дня до визита» и задайте вопрос «За сколько рабочих дней нужно направить заявку на пропуск?».

При сбое модели проверьте `reports/llm.stderr.log`. Launcher использует 24 слоя на GPU, один слот и 8192 токена контекста. При нехватке VRAM его можно перезапустить с меньшим `-GpuLayers`. Настройки поиска от этого не меняются.

Для воспроизводимости сохраните SHA кода, моделей, профилей и индекса командой `python -m scripts.build_release_manifest --index <индекс> --output reports/release-manifest.json`.

После изменения корпуса создайте новый снимок через интерфейс. Новая индексация включает путь документа в ID чанка и хранит пункты по паре «документ + версия». Приложение принимает собранный снимок или замороженный индекс, указанный в общем манифесте. При сбое сборки причина сохраняется в `last_build_error.json` рядом со снимками.

Для замера полного тракта задайте `NAVIGATOR_INDEX`, запустите локальную модель и выполните `python -m scripts.evaluate_unified --output reports/generation-research/full-fast-legacy150.jsonl`. Ключи `--retrieval` и `--generation` выбирают режимы. После сбоя можно повторить отсутствующие и ошибочные строки с `--retry-from <предыдущий файл>` и новым путём вывода. Для повтора используйте тот же индекс, модель и режимы.

Oracle на 150 вопросах запускается командой `python -m scripts.run_selected_generation --output reports/generation-research/oracle150.jsonl` при доступном локальном llama-server на порту 8091. Каталог вывода создаётся заранее. Для продолжения прогона укажите тот же путь и `--resume`, для итоговых метрик используйте `--summary`. Данные бенчмарка берутся из `data/hrag50` и `data/rag100`. Парное сравнение запускается через `python -m scripts.run_generation_research --dataset data/hrag50/hierarchical_complex_qa_50.jsonl --modes G0 G1 G2 --output reports/generation-research/paired.jsonl`.
