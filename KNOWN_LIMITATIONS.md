# Известные ограничения

- G2 экспериментальный. Цитаты проверяются дословно, а смысловой обзор выполняет та же модель. Полнота ответа независимо не подтверждена, поэтому статус G2 `answered` отображается как `partial`.
- Для списков G2 восстанавливает вводную часть и подпункт по структуре извлечённого текста. Форматы без видимых маркеров списка и списки с неоднозначной вложенностью требуют отдельной проверки. Межпакетный синтез ограничен одним набором взаимодополняющих фрагментов за запрос.
- Для 224 обязательных фактов измерено лексическое совпадение. Смысловая оценка ролей, сроков, отрицаний и исключений требует отдельной разметки ответов. Состояние прогонов приведено в EVALUATION_REPORT.md.
- Порядок действий нельзя выводить из порядка чанков. `depends_on` заполняется только при наличии проверенной связи между источниками. Fast и H1 не поставляют такие связи.
- Длинные пункты делятся на группы с отметкой неполноты. Дополнительный родитель ограничен двумя небольшими пунктами из Clause Store.
- Для исходников без проверенных символьных координат показывается локатор из ingestion, где он есть. Скачивание оригинала требует совпадения хеша редакции. Интерфейс не открывает PDF на нужной странице автоматически.
- Перестройка корпуса создаёт локальные снимки. Поиск использует активный снимок; предыдущие снимки и диагностические трассы остаются на диске. Интерфейс рассчитан на одного локального пользователя.
- Генерация выполняется по одному запросу за раз, с сетевыми тайм-аутами. Поиск и перестройка корпуса могут продолжаться во время генерации. Кнопка интерактивной отмены уже отправленного запроса не реализована.
- Windows launcher проверяет завершение процессов, принудительная остановка выполняется через Stop-Process.
