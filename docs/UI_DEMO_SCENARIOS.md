# Сценарии демонстрации

Все примеры ниже — вымышленные учебные документы, не правила МФТИ и не ответы живой Qwen.

## 1. Полная инструкция

В Demo Mode нажмите «Как забронировать переговорную?», затем «Получить ответ».
Ожидается краткий ответ, три шага, ссылка [1] и раскрывающийся источник «Учебный регламент бронирования переговорных», раздел 2. Нажмите [1], раскройте фрагмент, скопируйте цитату. Экспорт Markdown должен содержать вопрос, режим, ответ, шаги и полный использованный фрагмент. Повторный rerun не создаёт второй ответ.

## 2. Неполная информация

Создайте новый диалог. Выберите «Как подать заявку и сколько ждать?».
Статус partial, предупреждение о неполноте. Ответ подтверждает только передачу заявки координатору. Два источника; второй прямо не устанавливает срок. UI не подставляет выдуманный срок и не превращает это в техническую ошибку.

## Другие пути

- «Как забронировать комнату с оборудованием?» — два документа с независимыми ссылками.
- «Какова стоимость бронирования?» — insufficient без выдуманной суммы.
- «Кто согласует заявку при разных инструкциях?» — возможное, не установленное окончательно противоречие.
- «Показать ошибку подключения» — явно учебная техническая ошибка.
- «Какие сведения об оборудовании указать?» — длинное название источника.
- Документы → выберите PDF/DOCX/XLSX → сохранить → честный статус ожидания индексации → фильтр → удалить.
- Подключённый режим при выключенном сервере → реальная ошибка LLM, а не заранее записанный ответ.
