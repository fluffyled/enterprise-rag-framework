# Итерация C — связанные пункты (H2)

Гипотеза: расширение найденных пунктов по явным ссылкам («см. п. X»,
«в соответствии с пунктом Y») восстановит условия, определения и исключения,
необходимые для полного ответа.

## Реализация

- Граф связей в clause store (`scripts/build_clause_store.py`):
  `parent_id`, `previous_id`/`next_id` (порядок в документе), `references` —
  детерминированно извлечённые явные ссылки `(?:п.|пункт|раздел)\s*N.N`
  в тексте пункта. Итого 21 ребро references во всём корпусе из 439 пунктов.
- Расширение (`navigator/parent_expansion.py`, флаг `related_clauses`):
  один хоп по references после span-overlap расширения H1.
  Соседние пункты (next/prev) не добавляются — запрещено ТЗ без необходимости.

## Результаты (complex50, 50 вопросов)

| Конфиг | Clause Recall | Fact Coverage | All Found | Step Recall | Complete@all |
|---|---:|---:|---:|---:|---:|
| H1 @4000 | 0.914 | 0.912 | 0.680 | 0.426 | 0.100 |
| H2 @4000 | 0.914 | 0.912 | 0.680 | 0.429 | 0.060 |

По вопросам: 0 улучшено / 0 ухудшено — references не добавили ни одного нового
покрытого gold-пункта (все уже покрывались span-overlap H1).

## Вывод итерации C — нейтральный результат

1. В корпусе регламентов МФТИ явные перекрёстные ссылки почти не используются
   (21 ребро на 439 пунктов): процедуры конsecutive, а не перекрёстные.
   Механизм H2 корректен, но не имеет входных данных для работы.
2. H2 не принят как отдельное улучшение: эффект нулевой. Конфиг оставлен
   (`configs/retrieval_h2_related.yaml`), выключен по умолчанию.
3. Альтернативные связи (семантические, next/prev) по ТЗ требуют обоснования
   необходимости и не внедрялись.
